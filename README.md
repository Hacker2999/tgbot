# Телеграм-бот "Отвальный Бот"

## Описание

Многофункциональный Telegram-бот для групп и каналов с поддержкой антиспама, анти-рейда (капча), статистики пользователей, анекдотов, динамических ссылок, игровой системы Burmalda и гибкой системой команд. Все сообщения и интерфейс — на русском языке.

### Основные возможности
- **Антиспам**: автоматический мут за повторяющиеся сообщения (текст, стикеры, гифки, картинки), с увеличением срока за повторные нарушения. В чат выводится, кто и на сколько замучен.
- **Анти-рейд капча**: при входе нового пользователя бот ограничивает права и отправляет капчу-кнопку. Если не пройти капчу за 2 минуты — кик.
- **Фильтрация мусорных сообщений**: все сообщения, начинающиеся с `/` (команды для ботов), автоматически удаляются.
- **Система уровней**: автоматический подсчет опыта за сообщения, уровни и звания.
- **Система предупреждений**: накопительная система предупреждений с автоматическим баном после 3-х нарушений.
- **Приветствие и прощание**: настраиваемые сообщения при входе/выходе пользователя (отправляются после прохождения капчи).
- **🎮 Игровая система Burmalda**: полноценная игровая система с кредитами "отвальчики", играми (рулетка, слоты, блэкджек) и магазином.
- **🎭 Система RP-действий**: создание и использование ролевых действий при ответе на сообщения.
- **Команды для пользователей и админов**:
  - `/stat` — статистика пользователя (уровень, опыт, звание, отвальчики)
  - `/burmalda` — 🎮 игровая система с кредитами и магазином
  - `/set_welcome` — изменить приветствие (**только админ**)
  - `/set_bye` — изменить прощание (**только админ**)
  - `/rules` — правила чата
  - `/size` — измерить "размер" (рандом + никнейм из xyz.txt)
  - `/top` — Меню топов: размер беписа, количество сообщений, уровень, время в чате
  - `/links` — полезные ссылки с кнопками
  - `/add_button` и `/del_button` — управление кнопками (**только админ**)
  - `/anekdot` — случайный анекдот с baneks.site (с лимитом)
  - `/m` — мут пользователя (**только админ, ответом на сообщение**)
  - `/b` — бан пользователя (**только админ, ответом на сообщение**)
  - `/warn` — выдать предупреждение пользователю (**только админ, ответом на сообщение**)
  - `/unwarn` — снять все предупреждения у пользователя (**только админ, ответом на сообщение**)
  - `/help` — подробное меню со всеми командами
- **Динамические кнопки**: добавление/удаление ссылок через команды.
- **Интеграция с baneks.site**: свежие анекдоты по команде.
- **Уведомления о запуске/остановке**: бот сообщает о своём статусе в канал.
- **Гибкая настройка через config.py**.

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка_на_репозиторий>
   cd tgbot
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте файл `config.py`:**
   Внесите свои значения в следующие переменные:
   - `API_TOKEN` — токен Telegram-бота (обязательно)
   - `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT` — параметры подключения к PostgreSQL (обязательно)
   - `CHANNEL_CHAT_ID` — ID канала для уведомлений (обязательно)
   - `RULES` — текст правил чата (опционально)
   - `SPAM_LIMIT` — лимит одинаковых сообщений в минуту (опционально, по умолчанию 5)
   - `KILL_CHAT_PASSWORD` — пароль для команды полного уничтожения чата (опционально)

4. **Запустите бота:**
   ```bash
   python main.py
   ```

## Структура проекта
- `main.py` — запуск и инициализация бота, уведомления о старте/остановке
- `handlers.py` — все обработчики команд, событий и сообщений
- `middleware.py` — антиспам-мидлвар
- `ignore_old_messages.py` — игнорирование старых сообщений после рестарта бота
- `model.py` — peewee-модели для работы с БД
- `baneks_api.py` — получение анекдотов с baneks.site
- `utils.py` — утилиты (например, проверка лимита анекдотов, расчет уровней)
- `burmalda.py` — игровая система Burmalda с играми и магазином
- `config.py` — конфигурация (токены, параметры БД, лимиты и др.)
- `xyz.txt` — база для генерации никнеймов в команде /size
- `ranks.txt` — список званий для системы уровней
- `requirements.txt` — зависимости проекта

## Описание команд

### Пользовательские:
- **/stat** — Ваша статистика в чате: уровень, опыт, звание, время в чате, отвальчики
- **/burmalda** — 🎮 Игровая система с кредитами "отвальчики", играми и магазином
- **/size** — Узнай размер своего бубуя (рандом, стабилен в течение дня + никнейм)
- **/top** — Меню топов: размер пениса, количество сообщений, уровень, время в чате
- **/anekdot** — Получить свежий анекдот (лимит: 3 в день)
- **/rules** — Показать правила чата
- **/links** — Список полезных ссылок с кнопками
- **/help** — Подробное меню со всеми командами

### Админские:
- **/set_welcome** — Изменить приветствие (ответом на сообщение или текстом)
- **/set_bye** — Изменить прощание (ответом на сообщение или текстом)
- **/add_button** — Добавить кнопку в /links. Пример: `/add_button Название - https://ссылка`
- **/del_button** — Удалить кнопку из /links. Пример: `/del_button Название`
- **/m** — Мут пользователя (ответом на сообщение, можно указать срок: `/m 10m`)
- **/b** — Бан пользователя (ответом на сообщение, можно указать срок: `/b 1d`)
- **/add_rules** — Добавить или обновить правила чата (ответом на сообщение с текстом)
- **/warn** — Выдать предупреждение пользователю (ответом на сообщение). После 3-х предупреждений — автоматический бан
- **/unwarn** — Снять все предупреждения у пользователя (ответом на сообщение, только админ)
- **/add_action** — Добавить новое RP-действие. Пример: `/add_action "обнять" "обнял"`
- **/action_list** — Показать список всех RP-действий в чате
- **/del_action** — Удалить RP-действие. Пример: `/del_action "обнять"`
- `/tr_otval` — перевести отвальчики другому пользователю (только ответом на сообщение: `/tr_otval 100`)

## 🎮 Игровая система Burmalda

### Основные возможности:
- **Ежедневные кредиты**: каждый день пользователи получают 100 "отвальчиков"
- **Игры**: рулетка, слоты, блэкджек за 30 отвальчиков
- **Система попыток**: 3 попытки в рулетке и слотах, 1 попытка в блэкджеке
- **Награды за победы**:
  - 1 победа: 15 отвальчиков + 30 бонусного опыта
  - 2 победы: 35 отвальчиков + 60 бонусного опыта  
  - 3 победы: 60 отвальчиков + 90 бонусного опыта
- **Блэкджек**: победа = +60 отвальчиков, проигрыш = -30 отвальчиков, ничья = возврат 30 отвальчиков
- **Магазин**: снятие предупреждений, обмен отвальчиков на опыт

## 🎭 Система RP-действий

### Основные возможности:
- **Создание действий**: администраторы могут создавать ролевые действия для чата
- **Использование действий**: пользователи отвечают на сообщения с текстом действия
- **Кастомизация**: каждое действие можно настроить индивидуально для чата
- **Дополнительный текст**: можно добавить "со словами" к любому действию

### Как использовать:
1. **Администратор создает действие**: `/add_action "обнять" "обнял"`
2. **Пользователь отвечает на сообщение** с текстом "обнять"
3. **Бот автоматически** отправляет: "@Пользователь1 обнял @Пользователь2"

### Примеры использования:
- **Простое действие**: ответить "обнять" → "@Алекс обнял @Мария"
- **С дополнительным текстом**: ответить "обнять\nС любовью!" → "@Алекс обнял @Мария со словами: С любовью!"

### Команды управления:
- **/add_action "триггер" "действие"** — создать новое действие
- **/action_list** — показать все действия в чате
- **/del_action "триггер"** — удалить действие

## Особенности
- Бот игнорирует команды и сообщения, отправленные в период, когда он был выключен.
- Для работы некоторых команд бот должен быть админом с нужными правами.
- Для антиспама бот должен иметь права на ограничение пользователей и удаление сообщений.
- Для анти-рейда бот должен иметь права на ограничение и удаление пользователей.
- Файл `xyz.txt` должен существовать для работы команды `/size`.
- Система уровней автоматически начисляет опыт за каждое сообщение.
- При достижении нового уровня пользователь получает новое звание.
- Система предупреждений позволяет админам выдавать предупреждения за нарушения правил.
- После получения 3-х предупреждений пользователь автоматически получает бан.
- Ежедневно в 20:00 по МСК начисляется опыт за места в таблице размеров:
  - 1 место: 200 опыта
  - 2 место: 100 опыта
  - 3 место: 50 опыта
- При отправке сообщений есть 5% шанс получить от 100 до 500 бонусного опыта за активность.
