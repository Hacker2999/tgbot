# Телеграм-бот "Отвальный Бот"

## Описание

Многофункциональный Telegram-бот для групп и каналов с поддержкой антиспама, анти-рейда (капча), статистики пользователей, анекдотов, динамических ссылок и гибкой системой команд. Все сообщения и интерфейс — на русском языке.

### Основные возможности
- **Антиспам**: автоматический мут за повторяющиеся сообщения (текст, стикеры, гифки, картинки), с увеличением срока за повторные нарушения. В чат выводится, кто и на сколько замучен.
- **Анти-рейд капча**: при входе нового пользователя бот ограничивает права и отправляет капчу-кнопку. Если не пройти капчу за 2 минуты — кик.
- **Фильтрация мусорных сообщений**: все сообщения, начинающиеся с `/` (команды для ботов), автоматически удаляются.
- **Система уровней**: автоматический подсчет опыта за сообщения, уровни и звания.
- **Приветствие и прощание**: настраиваемые сообщения при входе/выходе пользователя (отправляются после прохождения капчи).
- **Команды для пользователей и админов**:
  - `/stat` — статистика пользователя (уровень, опыт, звание)
  - `/set_welcome` — изменить приветствие (**только админ**)
  - `/set_bye` — изменить прощание (**только админ**)
  - `/rules` — правила чата
  - `/size` — измерить "размер" (рандом + никнейм из xyz.txt)
  - `/size_top` — турнирная таблица размеров за сегодня
  - `/links` — полезные ссылки с кнопками
  - `/add_button` и `/del_button` — управление кнопками (**только админ**)
  - `/anekdot` — случайный анекдот с baneks.site (с лимитом)
  - `/roulette <минуты>` — русская рулетка: шанс получить мут на выбранное время
  - `/m` — мут пользователя (**только админ, ответом на сообщение**)
  - `/b` — бан пользователя (**только админ, ответом на сообщение**)
  - `/help` — подробное меню со всеми командами
- **Динамические кнопки**: добавление/удаление ссылок через команды.
- **Интеграция с baneks.site**: свежие анекдоты по команде.
- **Уведомления о запуске/остановке**: бот сообщает о своём статусе в канал.
- **Гибкая настройка через config.py**.

## Требования
- Python 3.8+
- PostgreSQL (рекомендуется версия 12+)
- Установленные зависимости из `requirements.txt`

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone <ссылка_на_репозиторий>
   cd tgbot
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте файл `config.py`:**
   Внесите свои значения в следующие переменные:
   - `API_TOKEN` — токен Telegram-бота (обязательно)
   - `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT` — параметры подключения к PostgreSQL (обязательно)
   - `CHANNEL_CHAT_ID` — ID канала для уведомлений (обязательно)
   - `RULES` — текст правил чата (опционально)
   - `SPAM_LIMIT` — лимит одинаковых сообщений в минуту (опционально, по умолчанию 5)
   - `KILL_CHAT_PASSWORD` — пароль для команды полного уничтожения чата (опционально)

4. **Запустите бота:**
   ```bash
   python main.py
   ```

## Структура проекта
- `main.py` — запуск и инициализация бота, уведомления о старте/остановке
- `handlers.py` — все обработчики команд, событий и сообщений
- `middleware.py` — антиспам-мидлвар
- `ignore_old_messages.py` — игнорирование старых сообщений после рестарта бота
- `model.py` — peewee-модели для работы с БД
- `baneks_api.py` — получение анекдотов с baneks.site
- `utils.py` — утилиты (например, проверка лимита анекдотов, расчет уровней)
- `config.py` — конфигурация (токены, параметры БД, лимиты и др.)
- `xyz.txt` — база для генерации никнеймов в команде /size
- `ranks.txt` — список званий для системы уровней
- `requirements.txt` — зависимости проекта

## Описание команд

### Пользовательские:
- **/stat** — Ваша статистика в чате: уровень, опыт, звание, время в чате
- **/size** — Узнай размер своего бубуя (рандом + никнейм)
- **/size_top** — Турнирная таблица размеров за сегодня
- **/anekdot** — Получить свежий анекдот (лимит: 3 в день)
- **/roulette <минуты>** — Русская рулетка! Пример: `/roulette 5` — если не повезёт, получите мут на 5 минут
- **/rules** — Показать правила чата
- **/links** — Список полезных ссылок с кнопками
- **/help** — Подробное меню со всеми командами

### Админские:
- **/set_welcome** — Изменить приветствие (ответом на сообщение или текстом)
- **/set_bye** — Изменить прощание (ответом на сообщение или текстом)
- **/add_button** — Добавить кнопку в /links. Пример: `/add_button Название - https://ссылка`
- **/del_button** — Удалить кнопку из /links. Пример: `/del_button Название`
- **/m** — Мут пользователя (ответом на сообщение, можно указать срок: `/m 10m`)
- **/b** — Бан пользователя (ответом на сообщение, можно указать срок: `/b 1d`)

## Особенности
- Бот игнорирует команды и сообщения, отправленные в период, когда он был выключен.
- Для работы некоторых команд бот должен быть админом с нужными правами.
- Для /roulette бот должен иметь право ограничивать пользователей.
- Для антиспама бот должен иметь права на ограничение пользователей и удаление сообщений.
- Для анти-рейда бот должен иметь права на ограничение и удаление пользователей.
- Файл `xyz.txt` должен существовать для работы команды `/size`.
- Система уровней автоматически начисляет опыт за каждое сообщение.
- При достижении нового уровня пользователь получает новое звание.
